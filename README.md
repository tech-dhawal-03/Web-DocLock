## ✨ Project Overview
Web DocLock is a secure digital vault to store **personal passwords** and **confidential documents.** It uses **AES encryption**🔒, **bcrypt hashing** for passwords, and AWS cloud for storage, ensuring top-notch security and easy access. 🗂️


🎯 **Goal:** Create a reliable and secure vault to protect sensitive data 💼, enhance data privacy 🔐, and offer easy categorization for quick retrieval 📂.

## 🔥 Features
| Feature                       | Description                                                   |
|-------------------------------|---------------------------------------------------------------|
| 🔐 AES Encryption             | Secure encryption of documents to protect sensitive information.     |
| 🔑 bcrypt Hashing             | Strong password hashing with salting to ensure safe user login..   |
| 🗂️ Document Categorization          | Organize documents and passwords for easy access and retrieval..  |
| 🔄 CRUD Operations| Create, Read, Update, and Delete operations on user data.|
| ☁️ AWS Cloud Integration	|Scalable and reliable cloud storage for user documents.
| 🧠 User-Friendly UI| imple and intuitive design for a seamless user experience.|
